# Вес — личный дневник

Статическое PWA на HTML, CSS и JavaScript. Без сборки, зависимостей и бэкенда. График нарисован SVG. Все данные остаются в localStorage браузера.

## Запуск

В папке проекта выполните `python3 -m http.server 8080` (или `npm start`) и откройте http://localhost:8080. Не открывайте index.html через file://: модулям и PWA нужен HTTP-сервер. Для установки и офлайн-режима нужен HTTPS либо localhost. После первого успешного открытия ресурсы кэшируются; приложение работает без сети. Установка — через меню браузера «Установить приложение» или «На экран Домой», если браузер поддерживает её.

## GitHub Pages

1. Загрузите содержимое папки в репозиторий GitHub.
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save.
3. Откройте адрес Pages. Все пути относительные, поэтому приложение работает и по адресу username.github.io/repository/.

Подходит любой хостинг статических файлов с HTTPS. Node.js и package.json нужны только для запуска тестов; сборки нет.

## Расчёты

Поле «На дату» по умолчанию содержит сегодняшний локальный день и задаёт конец графика и расчётов. Переключатель 7 / 30 / всё время меняет только видимый период графика.

- Среднее за 7 дней: выбранная дата D и шесть предыдущих дней, [D−6, D].
- Среднее за 30 дней: [D−29, D].
- Тренд: среднее [D−6, D] минус среднее [D−13, D−7]. Положительное значение означает рост веса.
- Пунктир на графике: такое же семидневное среднее для каждого дня. Для начала графика используются и записи до видимого периода.

Пустые дни исключаются из среднего. Если записей нет, отображается «—». Для тренда нужны записи в каждой из двух недель. Одна запись на дату; повторное сохранение заменяет вес. Допустим вес больше 0 и до 1000 кг включительно. Будущие записи сохраняются, но не входят в расчёты до выбора соответствующей даты.

## CSV и хранение

Экспорт содержит заголовок `date,weight`, даты YYYY-MM-DD и вес с десятичной точкой, UTF-8 BOM для совместимости с табличными редакторами. Импорт также принимает разделитель `;`, десятичную запятую и поля в кавычках. Пример:

```csv
date,weight
2026-10-08,72.5
2026-10-09,72.3
```

Импорт объединяет записи. Совпадения дат требуют подтверждения замены; последняя строка на дату побеждает. При ошибке весь импорт отменяется. Максимальный размер файла — 2 МБ.

Данные привязаны к браузеру и origin сайта, не синхронизируются между устройствами. Очистка браузера удаляет дневник; регулярно сохраняйте CSV. На одном origin экземпляры приложения используют общий ключ `weight-journal-v1`. При ошибке чтения сохранение блокируется, чтобы не затереть данные.

## Проверки и обновления

`npm test` — тесты календарных границ, средних, импорта и экспорта. Сторонние пакеты не нужны (Node.js 18+).

При изменении файлов увеличивайте версию CACHE в sw.js. Обновление активируется после закрытия старых вкладок приложения и повторного открытия; записи в localStorage сохраняются.
